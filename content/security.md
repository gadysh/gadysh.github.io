# אבטחה ושליטה

## העיקרון המרכזי: המידע שלכם נשאר אצלכם

אנחנו לא שומרים, לא מעבירים, ולא משתמשים בנתונים שלכם לשום מטרה מלבד לספק לכם את השירות. כל מידע נשאר בשליטתכם המלאה.

## ארכיטקטורות פריסה

### ענן פרטי (Private Cloud)
- סביבה ייעודית לארגון שלכם בלבד
- הפרדה מוחלטת מלקוחות אחרים
- שליטה מלאה על מיקום הנתונים (ישראל/אירופה/ארה"ב)

### On-Premise (באתר)
- כל התשתית רצה בשרתים שלכם
- אפס תנועת נתונים החוצה
- מתאים לארגונים עם דרישות אבטחה מחמירות

### היברידי
- חלק מהרכיבים בענן, חלק אצלכם
- גמישות מירבית
- מאזן אופטימלי בין אבטחה לנוחות

## הרשאות ושליטה

### ניהול הרשאות גרנולרי
- הגדרת הרשאות ברמת משתמש, תפקיד, ויחידה
- מי יכול לראות מה, לערוך מה, ולאשר מה
- תמיכה ב-SSO (Single Sign-On) ואינטגרציה עם Active Directory

### ביקורת ולוגים
- תיעוד מלא של כל פעולה
- מי ביצע מה, מתי, ועל איזה נתון
- יכולת audit trail מלאה לצורכי ציות רגולטורי

## הצפנה ואבטחת מידע

### הצפנה בכל שכבה
- הצפנה בתעבורה (TLS 1.3)
- הצפנה במנוחה (AES-256)
- הצפנה של מידע רגיש עוד לפני העברה למודלים

### אבטחת גישה
- אימות דו-שלבי (2FA/MFA)
- ניהול מפתחות מאובטח
- ביטול גישה מיידי בעת צורך

## ציות רגולטורי

### GDPR
- תמיכה מלאה בזכות הנשיה
- ייצוא ומחיקת נתונים אישיים
- הסכמי עיבוד נתונים (DPA) ברורים

### תקנות ישראליות
- ציות לחוק הגנת הפרטיות
- דיווח תקריות אבטחה לפי הנדרש
- שמירת נתונים בישראל (אם נדרש)

### תקני אבטחה
- עמידה בתקני ISO 27001
- ביקורות אבטחה תקופתיות
- הערכת סיכונים שוטפת

## מודלי AI ונתונים

### אילו מודלים אנחנו משתמשים?
- מודלים מובילים (GPT-4, Claude, Gemini) דרך API
- אופציה לשימוש במודלים פנימיים/מקומיים
- אופציה ל-fine-tuning על הנתונים שלכם (אם אתם רוצים)

### איך המידע עובר דרך המודלים?
- בגרסת ענן: הנתונים עוברים דרך API מוצפן
- ספקי המודלים (OpenAI/Anthropic/Google) התחייבו לא לשמור/לאמן על נתונים שעוברים דרך API ארגוני
- בגרסת on-premise: אפשר להריץ מודלים מקומיים לחלוטין (Llama, Mistral וכד')

### האם המידע משמש לאימון?
**לא.** אנחנו משתמשים רק ב-API ארגוניים שלא מאמנים על הנתונים שלכם. זה חלק מהחוזה עם ספקי המודלים.

## מה קורה במקרה של תקלה?

### גיבויים אוטומטיים
- גיבוי מלא כל 24 שעות
- גיבויים דרושים לשחזור מהיר
- אחסון בכמה מיקומים (לפי הצורך)

### זמינות גבוהה
- ארכיטקטורה מבוזרת (multi-AZ/multi-region)
- failover אוטומטי במקרה של תקלה
- SLA של 99.9% uptime (בגרסת ענן)

### תקשורת ותמיכה
- התראות מיידיות במקרה של אירוע
- ערוץ תקשורת ייעודי לארגון
- זמינות 24/7 (בחבילות enterprise)

## שאלות נפוצות

**ש: האם אתם יכולים לראות את הנתונים שלנו?**  
ת: רק אם אתם נותנים לנו הרשאה מפורשת (למשל לצורך תמיכה). בכל מקרה, גישה מתועדת ומבוקרת.

**ש: מה קורה אם נרצה להפסיק את השירות?**  
ת: אתם מקבלים את כל הנתונים, הקוד (אם רלוונטי), והמודלים שפיתחנו. אפס lock-in.

**ש: האם יש אפשרות לבדיקת חדירות?**  
ת: כן. אנחנו מעודדים ביקורות אבטחה ובדיקות חדירות (בתיאום מראש).
