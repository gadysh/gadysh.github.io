# הפעלת קולט הפניות של האתר, Google Apps Script

הקולט מקבל כל פנייה מהטופס, רושם אותה בגיליון Google ושולח התראה ל־contact@poworg.com. אחרי ההפעלה, כפתור "שליחת פנייה" באתר שולח ישירות ומציג "תודה, הפנייה התקבלה". מייל מוכן ייפתח רק כגיבוי, אם השליחה נכשלה.

ההפעלה לוקחת בערך 10 דקות, ונעשית פעם אחת מחשבון Google של PowOrg.

## לפני שמתחילים
- **החשבון:** הסקריפט מקבל רק שתי הרשאות: כתיבה לגיליון שהוא מחובר אליו ושליחת התראה במייל. לכן אפשר להפעיל אותו מ־gadi@poworg.com. חשבון ייעודי, כמו forms@poworg.com, מפריד עוד יותר, אבל עולה רישיון Workspace נוסף.
- **אימות דו־שלבי:** ודא שהוא פעיל בחשבון שממנו מפעילים. הגיליון יכיל פרטים של פונים.

## 1. יצירת הגיליון
1. ב־Google Drive של החשבון צור גיליון חדש בשם `PowOrg, פניות מהאתר`.
2. אל תשתף אותו עם אף אחד.

## 2. הדבקת הקוד
1. בגיליון: Extensions ואז Apps Script, בעברית תוספים ואז Apps Script.
2. שנה את שם הפרויקט, למעלה משמאל, ל־`PowOrg lead receiver`.
3. לחץ על גלגל השיניים, Project Settings, וסמן Show "appsscript.json" manifest file in editor.
4. חזור לעורך, Editor:
   - בקובץ `Code.gs` מחק את כל התוכן, והדבק את התוכן של `_dev/apps_script/Code.gs`.
   - בקובץ `appsscript.json` מחק את כל התוכן, והדבק את התוכן של `_dev/apps_script/appsscript.json`.
5. שמור עם Ctrl+S.

## 3. כתובת ההתראות
1. ב־Project Settings, תחת Script properties, לחץ Add script property.
2. ב־Property כתוב `NOTIFY_TO`, וב־Value כתוב `contact@poworg.com`. שמור.

## 4. הרצה ראשונה ואישור הרשאות
1. בעורך, בתפריט הפונקציות למעלה, בחר `setupSheet` ולחץ Run.
2. Google תבקש אישור. ייתכן שתופיע ההודעה "Google hasn't verified this app". זה תקין, כי זה סקריפט שלך. לחץ Advanced ואז Go to PowOrg lead receiver.
3. **בדוק את רשימת ההרשאות.** צריכות להופיע רק שתיים:
   - הצגה וניהול של גיליונות שהאפליקציה מותקנת בהם
   - שליחת אימייל בשמך
   אם מופיעה הרשאה אחרת, עצור ותכתוב לי.
4. אחרי ההרצה תופיע בגיליון לשונית `Leads`, עם שורת כותרות ותפריט סטטוס בעמודה B.

## 5. פרסום כ־Web app
1. למעלה מימין: Deploy, ואז New deployment.
2. ליד Select type לחץ על גלגל השיניים ובחר Web app.
3. מלא את השדות:
   - Description: `v1`
   - Execute as: Me
   - Who has access: Anyone
4. לחץ Deploy והעתק את ה־Web app URL. הכתובת מסתיימת ב־`/exec`.
5. **בדיקה:** פתח את הכתובת בדפדפן. צריך להופיע `{"ok":true,"code":"receiver_up"}`.

## 6. מחיקה אוטומטית אחרי 24 חודשים
1. בתפריט השמאלי לחץ על סמל השעון, Triggers, ואז Add Trigger.
2. מלא את השדות:
   - Function: `purgeOldLeads`
   - Event source: Time-driven
   - Type: Month timer
   - Day: 1
3. שמור.

הפונקציה מוחקת פניות בנות יותר מ־24 חודשים שלא הגיעו לשיחה. אלה פניות בסטטוסים new, ‏reviewed_fit או reviewed_not_now. זה מה שכתוב בעמוד הפרטיות.

## 7. מה לשלוח ל־Claude
שלח רק את ה־Web app URL. Claude מכניס אותו ל־`lead_endpoint` ב־`_config.yml`, שולח פנייה אחת לבדיקה מהאתר המקומי, ובודק שנוספה שורה בגיליון ושהגיעה התראה ל־contact@.

## עדכון הקוד בעתיד
1. Deploy, ואז Manage deployments.
2. לחץ על העיפרון, ובשדה Version בחר New version.
3. לחץ Deploy. הכתובת נשארת אותה כתובת, ואין צורך לשנות את האתר.

## מה הקולט עושה ולא עושה
- **בדיקת הפנייה:** הוא בודק כל פנייה: שדות חובה, אימייל תקין, אורך מקסימלי לכל שדה, וערכים מותרים בשדות הבחירה.
- **בוטים:** פנייה שהגיעה מבוט, עם שדה honeypot מלא, מקבלת תשובת הצלחה ולא נשמרת.
- **הגבלת קצב:** עד 20 פניות בדקה בסך הכל, ועד 3 בשעה מאותה כתובת מייל.
- **נוסחאות:** ערך שמתחיל ב־`=`, `+`, `-` או `@` נשמר כטקסט, ולא ירוץ כנוסחה בגיליון.
- **כתובת IP:** הוא לא שומר אותה, ובאפליקציה כזו היא גם לא זמינה לו.
