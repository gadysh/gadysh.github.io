# PowOrg Website (v2)

אתר התדמית והפתרונות של חברת PowOrg.

האתר בנוי כאתר סטטי ב־Jekyll המופעל ישירות על גבי GitHub Pages, ללא שרת ייעודי.

## כתובת ואירוח
- **כתובת ראשית**: https://poworg.com
- **פלטפורמת אירוח**: GitHub Pages (מאגר `gadysh.github.io`)
- **ענף ראשי (ייצור)**: `main`
- **ענף פיתוח v2**: `site-v2`

## ארכיטקטורה ומבנה קבצים
- `_config.yml` — הגדרות האתר, כתובת, תוספים (`jekyll-sitemap`, `jekyll-redirect-from`) והחרגות.
- `_data/` — קובצי נתונים ב־YAML:
  - `i18n.yml` — מחרוזות ממשק בעברית ובאנגלית.
  - `domains.yml` — שלושת תחומי הפתרון (שירות ומכירות, תפעול ומסמכים, ידע ועובדים).
  - `scenarios.yml` — חמשת תרחישי היכולת.
- `_layouts/` — תבניות עמוד (`base`, `page`, `domain`, `scenario`).
- `_includes/` — רכיבי ממשק משותפים (כותרת עליונה, כותרת תחתונה, כרטיסים, פירורי לחם, טופס פנייה).
- `assets/` — נכסים סטטיים: גליונות סגנון (`assets/css/site.css`), סקריפטים (`assets/js/site.js`), אייקונים ותמונות.
- עמודי עברית בשורש האתר (`/`), עמודי אנגלית תחת `/en/`.

## פיתוח ובדיקה מקומית
בסביבה שבה מותקנים Ruby ו־Jekyll:
```bash
bundle install
bundle exec jekyll serve
```
הערה: קבצים בתיקייה `_dev` מוחרגים מהפלט של האתר.
