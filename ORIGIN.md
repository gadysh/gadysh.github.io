## What this is
A version-controlled **working copy** of PowOrg's public site, brought into the company
repo so Marketing can develop it as org state. This is a plain static site
(HTML/CSS/JS + markdown content under `content/`, data in `data/site.json`).

## Important: this is NOT the live deployment
The live site is served by GitHub Pages from `gadysh/gadysh.github.io` (see `CNAME`).
Editing files here does **not** change the live site. Publishing changes back to the
live site is a separate push to the Founder's account and therefore **requires explicit
Founder approval per session** (`company/rules.md` #2.3 — no publishing under the
Founder's identity without approval).
